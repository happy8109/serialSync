# 新会话承接与开发唤醒工作流 (Session Bootstrap)

本技能用于在用户开启新会话并发出**“新会话”**或相关指令时，自动执行“开箱校验”，秒级找回前序会话沉淀的核心上下文、业务意图、架构原则与开发进度，彻底杜绝跨会话信息衰减与盲目猜想，快速向用户汇报并启动本轮核心工作。

---

## 核心执行流程

### 1. 深度调阅真实代码提交与唯一通用交接备忘录
激活此技能后，AI 必须第一时间按序执行以下步骤：
1. **查看真实代码提交历史与本地状态（第一物理证据）**：
   - 执行只读命令 `git status -s` 与 `git log -n 3 --stat`，核验本地仓库是否有未提交物理变更，以及最近的真实提交记录与文件变动范围；
2. **调阅动态状态唯一真理源 [docs/SESSION_HANDOFF.md](file:///docs/SESSION_HANDOFF.md)**：
   - **读取【当前进行中任务基准 (Active Context)】**：获取当前攻坚主线与版本基准；
   - **读取【核心业务与功能最新里程碑 (Core Feature Baseline)】**：提取核心业务提交注释、已就绪核心资产与架构原则，确保业务主干 100% 无损承接，绝不因辅助性工作流维护而丢失业务上下文；
   - 辅以查看【最近一次工程与工作流维护记录 (Last Workflow Maintenance)】（若有微调，同步最新规则规范）；
3. **核准全局规则与长期记忆宪章 [.agents/AGENTS.md](file:///.agents/AGENTS.md)**：
   - 确认核心协同底座、技术红线、交互铁律与反过度工程化原则。

---

### 2. 生成结构化《开局承接与上下文唤醒汇报》
调阅完成后，AI **无需输出多余客套话**，直接向用户输出清晰、干练的客观状态汇报，包含以下 4 个固定板块：

```markdown
### 🚀 新会话开发环境已就绪与上下文唤醒

#### 1. 📌 当前核心主线与版本基准
- **当前攻坚主线**：[模块名称 / 功能定义，如：用户鉴权中台与 Session 治理重构]
- **当前版本基准**：[版本号，如：1.0.0.12]

#### 2. 📝 核心业务里程碑参考 (Core Business Baseline)
- **提交主旨与关键修改**：[提取核心业务里程碑的提交注释要点，精准还原最新业务功能进展]

#### 3. 🧱 最新已就绪核心资产 (严禁重复返工)
- [提取核心业务里程碑中的底层支撑、核心 API、数据模型或 UI 成果，明确哪些模块已就绪，不可推翻重写]

#### 4. ⚠️ 本轮开发关键技术红线与交互铁律
- [列出本轮开发必须死守的原则，如：软删除 is_delete 规范 / 业务逻辑零硬编码 / 防 N+1 批量优先 / 成功操作静默响应等]

---
当前上下文与系统状态已核准对齐，请指示下一步工作。
```

---

### 3. 输出红线与交互约束（绝对红线）
- **严禁提供下一步开发建议**：新会话开局汇报的核心职责是“对齐基准、核准状态、唤醒长期记忆”。**严禁在汇报中自行列出“建议的第 1 步切入方案”、“推荐的攻坚目标”或任何诱导性待办建议**。新会话的具体工作任务完全由用户下达；
- **纯粹待命**：输出汇报后，AI 必须停下等待用户明确的下一步工作指令，严禁在未获指令前擅自执行代码改动或假设开发路线。
